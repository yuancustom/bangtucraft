# ADR 0002：阶段一前端使用 React + 手写 CSS，暂不引入 shadcn/ui

- 日期：2026-11-06
- 状态：已采用（阶段四可重新评估）

## 决定
计划的技术栈写了 shadcn/ui。阶段一的界面只需要会话列表、对话流、几类卡片（批准、提问、计划、文件）和两个表格页面，用 React + 一份 `style.css` 就能完成，避免同时引入 Tailwind、Radix 和组件生成脚本。

## 影响
- 依赖更少，构建更快；视觉一致性靠 `style.css` 中的少量变量维护。
- 阶段四做文件树、终端面板、diff 视图时组件会明显变多，届时再决定是否迁移到 shadcn/ui。
